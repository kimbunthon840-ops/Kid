# 🎨 Kiddle - Early Childhood Education & Kindergarten Website

Welcome to **Kiddle Early Childhood Academy**, a modern, responsive, playful, and high-performance multi-page website template designed specifically for preschools, daycares, kindergartens, and early learning centers.

---

## 🌟 Live Demo & Preview
- **GitHub Pages Demo:** `https://kimbunthon840-ops.github.io/Kidle/`
- **Local Preview:** Simply open `index.html` in any web browser or use VS Code Live Server.

## 🚀 Key Features

- **Responsive Design:** Fluid layout optimized for desktops, tablets, and smartphones.
- **Friendly & Joyful Aesthetics:** Curated vibrant color palette (Radiant Coral `#FF5630`, Sunny Gold `#FFB020`, Fresh Emerald `#10B981`, Midnight Slate `#0F172A`) with high-clarity typography (*Fredoka*, *Plus Jakarta Sans*, *Kantumruy Pro*).
- **Interactive UI Components:**
  - 📢 **Top Running Announcement Marquee:** Infinite-loop live admission announcements, scholarship discounts & campus tour reminders
  - 📌 Sticky Navigation Bar with active path highlight and mobile responsive toggle
  - 📊 Animated Number Counters for school statistics
  - 🧩 Dynamic Class Filtering by age category (Toddlers, Preschool, Kindergarten)
  - 📅 Interactive Tour & Appointment Booking modal
  - 💬 Parent Testimonial reviews and rating cards
  - ❓ Collapsible FAQ Accordion with smooth height transitions
  - ⬆️ Smooth Scroll-To-Top button
  - 💌 Newsletter & Contact forms with instant feedback

## ⚙️ How to Deploy on GitHub Pages

1. **Upload Files to GitHub:**
   - Go to your repository on GitHub (e.g. `github.com/kimbunthon840-ops/Kidle`).
   - Click **Add file** -> **Upload files**.
   - Drag and drop all project files (including `.nojekyll`, `index.html`, `style.css`, `main.js`, `favicon.svg`, and the folders).
   - Click **Commit changes**.

2. **Enable GitHub Pages:**
   - In your repository, go to **Settings** -> **Pages**.
   - Under **Build and deployment**:
     - **Source**: Select `Deploy from a branch` (Branch: `main`, Folder: `/ (root)`), OR select `GitHub Actions`.
     - Click **Save**.
   - Wait 1–2 minutes, then visit your live URL:
     `https://<username>.github.io/<repository-name>/`
